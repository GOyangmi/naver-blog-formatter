1. 기본 원칙

Subpath Laboratory는 블로거를 위한 안내서에서 사용자가 입력한 글을 서버로 전송하거나 데이터베이스에 저장하지 않습니다. 가독성 진단, 오탈자 점검, 문단 정리, 글 작성은 모두 사용자의 브라우저 안에서만 처리됩니다.

사이트 코드에는 입력 내용을 외부로 보내는 기능 자체가 없습니다. 전체 코드가 공개돼 있어 직접 확인할 수 있습니다.

2. 진단 도구에 입력하는 글

가독성 진단, 오탈자 점검, 문단 정리 화면에 붙여 넣은 글은 현재 페이지의 메모리에만 존재합니다. 저장하지 않으며, 페이지를 새로고침하거나 닫으면 사라집니다.

3. 글 작성 기능과 브라우저 로컬 저장소

글 작성 화면에서 쓴 글은 사용자의 브라우저 로컬 저장소(localStorage)에 저장됩니다. 이는 사용자의 기기 안에만 존재하는 저장 공간이며, 운영자에게 전송되지 않고 운영자가 열람할 수도 없습니다.

  • 저장 항목: 사용자가 입력한 제목, 본문, 마지막 수정 시각
  • 저장 위치: 사용자의 브라우저 (기기 밖으로 나가지 않음)
  • 보관 기간: 사용자가 삭제할 때까지
  • 삭제 방법: 글 작성 화면의 이 글 삭제 또는 저장된 글 전부 삭제, 혹은 브라우저의 사이트 데이터 삭제

같은 기기·같은 브라우저에서만 보입니다. 다른 기기에서는 동기화되지 않으며, 브라우저 데이터를 지우거나 시크릿 모드를 사용하면 저장된 글이 사라집니다. 중요한 글은 파일로 내려받아 따로 보관하시기 바랍니다.

공용 컴퓨터에서 사용하셨다면 자리를 뜨기 전에 저장된 글을 삭제해 주세요.

4. 접속 과정에서 처리될 수 있는 정보

사이트는 GitHub Pages를 통해 제공되며, 호스팅 사업자는 보안과 서비스 운영을 위해 일반적인 접속 로그를 처리할 수 있습니다. 이 로그의 처리는 해당 사업자의 정책을 따릅니다.

5. Google AdSense

Google AdSense가 안내서와 도구 페이지에서 쿠키, 기기 정보, 광고 식별자와 같은 정보를 처리할 수 있습니다. 소개, 개인정보 처리방침, 이용약관, 문의 페이지에는 광고 코드를 로드하지 않습니다.

광고와 관련한 개인정보 처리 및 선택권은 Google의 관련 정책과 동의 관리 화면을 따릅니다. 광고 개인 최적화는 Google 광고 설정에서 해제할 수 있습니다.

6. 쿠키와 동의

운영자는 자체적인 회원 식별 쿠키나 분석 도구를 사용하지 않습니다. 3항의 로컬 저장소는 쿠키가 아니며 서버로 전송되지 않습니다.

Google 광고가 활성화된 경우 지역에 따라 광고 관련 동의 메시지가 표시될 수 있습니다. 유럽경제지역, 영국, 스위스 등 동의가 필요한 지역에는 Google이 요구하는 인증된 동의 관리 플랫폼 설정을 적용합니다.

7. 외부 링크

사이트에는 다른 웹사이트로 이동하는 링크가 포함될 수 있습니다. 외부 사이트에서 이뤄지는 정보 처리는 해당 사이트의 개인정보 처리방침을 따릅니다.

8. 이용자의 권리

이 사이트는 개인을 식별할 수 있는 정보를 수집·보관하지 않으므로 열람이나 정정을 요청할 대상 정보가 없습니다. 브라우저에 저장된 글은 사용자가 직접 언제든 삭제할 수 있습니다.
