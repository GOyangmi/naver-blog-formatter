반려 메일에는 "가치가 별로 없는 콘텐츠" 같은 짧은 문구만 옵니다. 어디가 문제인지 안 알려 줍니다. 그래서 무엇을 고쳐야 할지 모른 채 재신청을 반복하게 됩니다.

신청 전 조건

공식 문서에 "글 몇 편 이상"이라는 숫자는 없습니다. 다만 실제 심사에서 통과되는 사이트들의 공통점은 있습니다.

  • 실질 콘텐츠 페이지 20개 이상 — 얇은 글 50개보다 충실한 글 20개가 낫습니다
  • 페이지마다 충분한 분량 — 정보성 글이면 1,500자 이상은 되어야 질문에 답이 됩니다
  • 검색에 색인돼 있을 것 — 색인 안 된 페이지는 심사에서 없는 것으로 봅니다
  • 개인정보 처리방침 — 필수입니다. 광고 쿠키에 대한 고지가 들어가야 합니다
  • 소개·문의 페이지 — 누가 운영하는지 확인할 수 있어야 합니다
  • 탐색이 명확할 것 — 메뉴로 모든 글에 닿을 수 있어야 합니다
  • 전부 원본 — 옮겨 온 글이 있으면 그것만으로 반려됩니다
색인 확인이 가장 자주 빠집니다

글을 아무리 많이 써도 구글이 아직 수집하지 않았으면 심사에서 보이지 않습니다. Search Console → 색인 생성 → 페이지에서 "색인이 생성됨"이 20개 이상인지 먼저 확인하고 신청하세요.

반려 사유별 대응

"가치가 별로 없는 콘텐츠"

가장 흔합니다. 대개 페이지 수 부족이거나 색인 미완료입니다. 글 길이 문제로 오해하기 쉬운데, 한 편을 길게 늘리는 것보다 충실한 글을 더 쓰는 편이 효과적입니다.

다른 곳의 정보를 요약만 한 글, 목록만 나열한 글, 검색어를 반복한 글도 여기 해당합니다.

"사이트가 다운되었거나 사용할 수 없음"

크롤러가 접근을 못 한 경우입니다. `robots.txt`가 차단하고 있는지, 사이트가 실제로 열리는지, 도메인 연결이 끝났는지 확인하세요. 신청 직후 사이트를 옮기면 이 오류가 납니다.

"복제된 콘텐츠"

다른 곳의 글이 들어 있다는 뜻입니다. 인용이라도 비중이 크면 걸립니다. 해당 글을 지우거나 내 말로 다시 쓰세요.

"탐색이 어려움"

메뉴에서 글로 닿을 수 없거나, 링크가 깨져 있거나, 모바일에서 조작이 안 되는 경우입니다.

재신청할 때

반려 후 바로 재신청하는 것이 가장 흔한 실수입니다. 아무것도 안 바뀐 상태로 다시 내면 다시 반려됩니다. 그리고 반복하면 심사가 더 까다로워집니다.

권장 순서 1. 반려 사유에 해당하는 부분을 실제로 고친다 2. 새 글을 충분히 추가한다 3. Search Console에서 색인 생성을 요청한다 4. 색인 수가 20개를 넘을 때까지 기다린다 (보통 1~2주) 5. 그때 재검토를 요청한다

승인 후

자동 광고와 수동 배치

자동 광고는 구글이 알아서 위치를 정합니다. 편하지만 가끔 이상한 곳에 들어갑니다. 수동 배치는 직접 정하는 방식이라 손이 가는 대신 통제가 됩니다.

처음에는 자동으로 시작하고, 배치가 거슬리면 수동으로 바꾸는 순서가 무난합니다.

광고 개수

많이 붙일수록 수익이 느는 건 어느 지점까지입니다. 그 뒤로는 사람들이 나가서 오히려 줄어듭니다. 그리고 광고가 본문보다 많으면 정책 위반입니다.

절대 하면 안 되는 것

  • 자기 광고 클릭 — 계정 정지 사유 1위입니다. 실수로도 누르지 마세요
  • 클릭 유도 — "광고 한 번 눌러 주세요"는 즉시 위반입니다
  • 다른 사람에게 클릭 부탁 — 구글은 패턴으로 잡아냅니다
  • 광고를 콘텐츠처럼 위장 — 버튼이나 메뉴 바로 옆에 붙이는 것도 포함됩니다

정지되면 대개 복구되지 않습니다. 그리고 그동안 쌓인 수익도 지급되지 않습니다.

수익 구조

수익은 노출 수 × 클릭률 × 클릭당 단가로 정해집니다. 이 중 단가는 내가 못 정합니다. 분야가 정합니다.

금융·보험·부동산·법률은 높고, 일상·연예·게임은 낮습니다. 열 배 이상 차이 나기도 합니다. 그렇다고 아는 것도 없는 분야로 옮기면 글이 얕아져서 결국 유입이 안 옵니다.

현실적으로는 단가를 올리려 애쓰기보다 유입을 늘리는 편이 낫고, 그보다 제휴나 내 상품을 섞는 편이 효율적입니다.
